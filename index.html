🛡️ Attacks By Layer

Volumetric - Layer 3/4: Flood to clog bandwidth.
Protocol - Layer 3/4: Exploit TCP/IP to exhaust server.
Application - Layer 7: Attack one app/website.
TLDR: Layer 3+4 knock whole network, Layer 7 crash one site.

IP Address? Unique number for device, like house address. Example: 192.168.1.10, 10.0.0.5, 172.16.1.100

Defend: Firewall, rate-limit, Cloudflare, update server. Never test on site wey no be yours!
